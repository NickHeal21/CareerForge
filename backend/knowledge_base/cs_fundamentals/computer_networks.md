# CS Fundamentals — Computer Networks

## OSI & TCP/IP Model
- 7 layers of OSI: Physical, Data Link, Network, Transport, Session, Presentation, Application
- TCP/IP 4-layer model mapping
- Protocols at each layer

## Key Protocols
- **HTTP/HTTPS**: Methods, status codes, headers, REST principles
- **TCP vs UDP**: Reliability vs speed, use cases
- **DNS**: Resolution process, record types (A, AAAA, CNAME, MX)
- **DHCP**: Dynamic IP allocation
- **ARP**: IP to MAC address resolution

## Transport Layer
- TCP 3-way handshake (SYN, SYN-ACK, ACK)
- TCP flow control (Sliding Window)
- TCP congestion control (Slow Start, AIMD)
- Port numbers: Well-known, Registered, Dynamic

## Network Layer
- IPv4 vs IPv6
- Subnetting and CIDR notation
- NAT (Network Address Translation)
- Routing: RIP, OSPF, BGP

## Security
- Symmetric vs Asymmetric encryption
- TLS/SSL handshake
- Firewalls, VPNs, IDS/IPS
- Common attacks: DDoS, MITM, DNS Spoofing

## Interview Questions
- What happens when you type google.com in a browser?
- Explain TCP 3-way handshake
- Difference between TCP and UDP — when to use each?
- What is DNS? Explain the resolution process
- How does HTTPS work? Explain TLS handshake
- What is a subnet mask? How does subnetting work?
