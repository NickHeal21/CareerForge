# Career Guidance — Software Engineering

## Roles & Career Paths
- **Frontend Engineer**: React/Angular/Vue → Senior → Staff → Principal
- **Backend Engineer**: APIs, databases, distributed systems → Architect
- **Full Stack Engineer**: End-to-end development → Tech Lead
- **DevOps/SRE**: CI/CD, infrastructure, observability → Platform Engineer
- **Mobile Engineer**: React Native, Flutter, Swift, Kotlin

## What Companies Look For (Entry Level)
1. Strong DSA fundamentals (LeetCode medium level)
2. One programming language mastery
3. 2-3 meaningful projects with clean code
4. Understanding of web development (frontend + backend)
5. Basic system design knowledge
6. Communication skills and teamwork
7. Eagerness to learn and grow

## Application Strategy
- Apply to 50-100 companies (shotgun + targeted)
- Customize resume for each major application
- Leverage referrals — 5x higher callback rate
- Active GitHub profile with pinned projects
- LinkedIn optimization with relevant keywords
- Contribute to open source for credibility

## Salary Negotiation Tips
- Research market rates (Levels.fyi, Glassdoor, Blind)
- Never give a number first
- Consider total compensation (base + bonus + equity + benefits)
- Practice negotiation conversations
- Get competing offers when possible
- Be respectful but firm

## Continuous Growth
- Read engineering blogs (Netflix, Uber, Airbnb, Stripe)
- Attend meetups and conferences
- Build side projects continuously
- Mentor juniors — teaching deepens understanding
- Stay updated with industry trends
