# AI/ML Learning Roadmap

## Phase 1: Math & Programming Foundations (Weeks 1-4)
### Mathematics
- Linear Algebra: Vectors, matrices, eigenvalues, SVD
- Calculus: Derivatives, gradients, chain rule, partial derivatives
- Probability & Statistics: Bayes theorem, distributions, hypothesis testing
- Optimization: Gradient descent, convex optimization

### Programming
- Python proficiency (NumPy, Pandas, Matplotlib)
- Jupyter Notebooks workflow
- Data manipulation and visualization

## Phase 2: Machine Learning (Weeks 5-10)
### Supervised Learning
- Linear Regression, Logistic Regression
- Decision Trees, Random Forests, Gradient Boosting (XGBoost)
- SVM, KNN, Naive Bayes
- Model evaluation: Precision, Recall, F1, AUC-ROC, Cross-validation

### Unsupervised Learning
- K-Means, DBSCAN, Hierarchical Clustering
- PCA, t-SNE for dimensionality reduction
- Association rules

### ML Engineering
- Scikit-learn mastery
- Feature engineering and selection
- Hyperparameter tuning (Grid/Random/Bayesian)
- Model serialization and deployment

## Phase 3: Deep Learning (Weeks 11-16)
### Neural Networks
- Perceptron, MLP, backpropagation
- CNNs for computer vision
- RNNs, LSTMs, GRUs for sequential data
- Transformers and attention mechanism

### Frameworks
- PyTorch (preferred for research)
- TensorFlow/Keras (production)
- Hugging Face Transformers

## Phase 4: Specialization (Weeks 17-20)
### NLP
- Text preprocessing, embeddings (Word2Vec, GloVe)
- BERT, GPT architectures
- Sentiment analysis, NER, text classification
- LLMs and prompt engineering

### Computer Vision (Alternative)
- Image classification, object detection
- YOLO, ResNet, EfficientNet
- Image segmentation

## Phase 5: Projects & Interview Prep (Weeks 21-24)
- End-to-end ML project with deployment
- Kaggle competitions
- Research paper reading
- ML system design interviews
