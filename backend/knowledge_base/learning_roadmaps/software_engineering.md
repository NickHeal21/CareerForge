# Software Engineering Learning Roadmap

## Phase 1: Foundations (Weeks 1-4)
### Programming Fundamentals
- Pick one language deeply: Python, Java, or JavaScript
- Variables, data types, control flow, functions
- OOP concepts: Classes, inheritance, polymorphism
- Error handling, file I/O

### Data Structures
- Arrays, Strings, Linked Lists
- Stacks, Queues, Hash Maps
- Trees (Binary, BST), Heaps
- Graphs (representation, traversal)

## Phase 2: Core CS (Weeks 5-8)
### Algorithms
- Sorting (Merge, Quick, Heap)
- Searching (Binary Search variations)
- Dynamic Programming (patterns)
- Greedy, Backtracking, Divide & Conquer
- Practice: LeetCode 100-150 problems

### CS Fundamentals
- Operating Systems: Process, Memory, File Systems
- DBMS: SQL, Normalization, Transactions
- Computer Networks: TCP/IP, HTTP, DNS
- OOP & Design Patterns

## Phase 3: Development Skills (Weeks 9-14)
### Web Development
- Frontend: HTML, CSS, JavaScript, React
- Backend: Node.js/Express or Python/FastAPI
- Databases: PostgreSQL, MongoDB
- REST APIs, Authentication (JWT, OAuth)

### Tools & Practices
- Git & GitHub (branching, PRs, collaboration)
- Linux/CLI basics
- Docker fundamentals
- CI/CD basics (GitHub Actions)

## Phase 4: Projects & Portfolio (Weeks 15-18)
- Build 3-4 substantial projects
- Include at least one full-stack project
- Deploy projects (Vercel, Railway, AWS)
- Write clean READMEs with demos

## Phase 5: Interview Prep (Weeks 19-24)
- DSA practice: 2-3 problems daily
- System Design: Study 10 classic problems
- Resume optimization
- Mock interviews (technical + HR)
- Company research and application strategy
