# Resume Best Practices & ATS Optimization

## Resume Structure
1. **Contact Information**: Name, email, phone, LinkedIn, GitHub, portfolio
2. **Professional Summary**: 2-3 lines highlighting key skills and goals
3. **Education**: Degree, university, GPA (if > 3.5), relevant coursework
4. **Technical Skills**: Organized by category (Languages, Frameworks, Tools, Databases)
5. **Experience**: Internships, part-time roles — use STAR format
6. **Projects**: 3-4 relevant projects with tech stack and impact
7. **Certifications**: Relevant certifications only
8. **Achievements**: Hackathons, competitive programming, publications

## ATS Optimization Rules
- Use standard section headings (Education, Experience, Skills)
- Avoid tables, images, headers/footers, text boxes
- Use standard fonts (Arial, Calibri, Times New Roman)
- Save as PDF (preserves formatting)
- Include keywords from the job description naturally
- Use full terms AND acronyms (e.g., "Machine Learning (ML)")
- Keep to 1 page for < 3 years experience, 2 pages max
- Use reverse chronological order

## Power Verbs for Bullet Points
- **Built**: Developed, Engineered, Architected, Implemented
- **Improved**: Optimized, Enhanced, Streamlined, Accelerated
- **Led**: Managed, Coordinated, Spearheaded, Mentored
- **Analyzed**: Researched, Evaluated, Assessed, Investigated

## Quantify Impact
- "Improved API response time by 40% through Redis caching"
- "Built a dashboard serving 500+ daily active users"
- "Reduced deployment time from 30 minutes to 5 minutes using CI/CD"
- "Achieved 95% accuracy on sentiment analysis using BERT"

## Common Mistakes
- Including irrelevant personal information (age, photo, marital status)
- Using generic objective statements
- Listing responsibilities instead of achievements
- Poor formatting or inconsistent styling
- Spelling and grammar errors
- Including every technology you've ever touched
