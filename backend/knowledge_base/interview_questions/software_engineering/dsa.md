# Data Structures & Algorithms — Interview Questions

## Arrays & Strings
- Two Sum, Three Sum, Container With Most Water
- Sliding Window: Maximum subarray, Minimum window substring
- Two Pointers: Remove duplicates, Trapping rain water
- Kadane's Algorithm for maximum subarray sum
- Rotate array, Spiral matrix traversal

## Linked Lists
- Reverse a linked list (iterative and recursive)
- Detect cycle (Floyd's algorithm)
- Merge two sorted linked lists
- Remove Nth node from end
- LRU Cache implementation

## Stacks & Queues
- Valid parentheses, Min stack
- Next greater element
- Implement queue using stacks
- Sliding window maximum
- Evaluate reverse polish notation

## Trees & Graphs
- Binary tree traversals (inorder, preorder, postorder, level-order)
- Validate BST, Lowest Common Ancestor
- Maximum depth, Diameter of binary tree
- BFS and DFS on graphs
- Topological sort, Detect cycle in directed graph
- Dijkstra's shortest path, Bellman-Ford
- Kruskal's and Prim's MST algorithms

## Dynamic Programming
- Fibonacci, Climbing stairs
- 0/1 Knapsack, Unbounded knapsack
- Longest Common Subsequence, Longest Increasing Subsequence
- Coin change, Edit distance
- Matrix chain multiplication
- DP on trees, DP on intervals

## Sorting & Searching
- Binary search variations (first/last occurrence, rotated array)
- Merge sort, Quick sort — time/space analysis
- Counting sort, Radix sort — when to use
- Kth largest/smallest element (Quick Select)

## Greedy Algorithms
- Activity selection, Job sequencing
- Huffman coding
- Fractional knapsack
- Interval scheduling

## Backtracking
- N-Queens, Sudoku solver
- Permutations, Combinations, Subsets
- Word search, Letter combinations of phone number

## Complexity Analysis
- Big O, Omega, Theta notation
- Amortized analysis
- Space-time tradeoffs
- Recurrence relations (Master theorem)
